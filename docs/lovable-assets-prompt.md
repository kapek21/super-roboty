# Lovable — Super Roboty assets

Pakiet już wygenerowany (`super-roboty-assets.zip`) zawiera to, czego trzeba do MVP. **Nie dosyłaj kolejnych pojedynczych klocków**, chyba że chcesz wariant kolorystyczny tej samej części.

W zipie są:

- całe boty: `robot_ranger_colorful`, `robot_ninja`, `robot_dino_mecha`, `robot_combiner`, `robot_small`, `robot_large`
- części: `part_leg_left/right`, `part_arm_left/right`, `part_torso`, `part_head`, `part_connector`
- komendy: `cmd_attach`, `cmd_rotate`, `cmd_bolt`, `cmd_test_walk`
- tło: `bg_workshop.png`

Gdybyś robił nowy zestaw, wklej:

```
Brick-built toy game art (NOT LEGO brand, no minifigure trademark, no logos, no watermarks). Chunky plastic bricks with visible studs, 3/4 isometric, sharp edges, no photoreal, no blur. Transparent PNG, one subject per file, ~10% margin, no ground plane, no baked drop shadow, no text. Palette: navy #102870, sky #78c8f8, brick-yellow #fce874, brick-red #e40058, brick-blue #5c94fc, brick-green #40e878, white #fcfcfc, dark stud #181028. Kids 5–6, silhouettes readable at 64px.

Do not draw Power Rangers, Ninjago, Voltron, LEGO logo, or catalog minifig faces.
```
