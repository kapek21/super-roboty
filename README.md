# Super Roboty

Gra rodzinna: sekwencja części (noga → tors → głowa), potem robot „idzie”. **Nie jest grą BoS.**

Galeria budowniczego jest ta sama co w Super Trasie (zwierzątka / kostki / ludziki).

```bash
cd super-roboty
npm install
npm run dev
```
